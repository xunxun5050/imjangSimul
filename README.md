# 임장 시뮬레이터

![character](imjang-character-28x33.png)

수도권 아파트 매매 · 실거주 1채를 다루는 브라우저 기반 1인용 시뮬레이션 게임.

캐릭터의 소득·현금·우선순위를 정하면, 정해진 기간 동안 매물을 보러 다니다가 한 채를 계약합니다. 대출 한도(LTV·DSR·6억 상한)를 실제로 계산해서 그 범위 안에서만 매물이 나오고, 호가 변동·시장 이벤트·경쟁 매수인 같은 통제 불가능한 변수가 결과를 흔듭니다. 반드시 집을 사는 게임은 아닙니다 — 무주택 엔딩도 있습니다.

## 실행 방법

빌드 도구 없이 `imjang-simulator.html` 파일 하나만 브라우저로 열면 바로 플레이할 수 있습니다.

```bash
open imjang-simulator.html
```

또는 정적 파일 서버로 띄워도 됩니다.

```bash
npx serve .
```

## 주요 기능

- **캐릭터 설정** — 소득, 현금, 기존 대출, 직장(14곳), 가구 형태, 생애최초 여부, 우선순위(10종 중 최대 2개), 임장 기간(1~12개월), 임장 갈 지역(36개 지역 중 다중·전체 선택)
- **예산 기반 매물 생성** — LTV·DSR·6억 절대 한도로 계산한 실제 대출 한도 안에서만 매물이 나옵니다
- **시작 인트로 몽타주** — 캐릭터가 서울 경계·한강이 표시된 지도 위를 이동하며 여러 지역을 훑는 연출
- **임장 루프** — 가계약금 넣기 · 가격 협상 · 관심 매물 등록 · 그냥 넘기기 · 쉬기 · 재방문
- **시장·현장 이벤트**, heat(경쟁 과열도) 시스템으로 매주 상황이 달라짐
- **임장 동선 / 임장 일지** — 언제 어디를 봤고 어떻게 됐는지 시간순 기록
- **계약 성공 시** — 계약서 카드, 자금 조달 내역, 만족도 점수, 1년 뒤 시세 변화
- **미계약 시** — 무주택 엔딩

## 기술 스택

- 순수 HTML/CSS/JS **단일 파일**. 프레임워크·빌드 도구·백엔드 없음
- 외부 의존성은 Google Fonts(Black Han Sans, IBM Plex Sans KR) 뿐이며, 로드 실패 시 시스템 한글 폰트로 폴백
- 영속 저장 없음 — 새로고침하면 초기화됩니다
